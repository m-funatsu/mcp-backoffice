# v3.2.0 エンタープライズ設定管理コンソール 設計書

## 1. 概要

### 1.1 目的
AIエージェントの強力な自律性をエンタープライズ環境で安全かつ効果的に運用するための統合管理インターフェースを提供する。

### 1.2 背景
- AI-Native Enterprise Operating System (AI-OS)として、企業全体のパフォーマンスを最適化
- 複数のAIエージェントが自律的に動作する環境での統制とガバナンスの必要性
- エンタープライズ顧客からの設定管理・権限制御の要求

### 1.3 スコープ
- 役割と権限管理 (RBAC)
- AIエージェント設定管理
- インテグレーション管理
- 監査ログとコンプライアンス
- ハイブリッド設定インターフェース（GUI + AI会話型）

## 2. 機能要件

### 2.1 統合管理ダッシュボード

#### 2.1.1 役割と権限管理 (RBAC)
```typescript
interface RoleDefinition {
  id: string;
  name: string;
  description: string;
  permissions: Permission[];
  priority: number;
  createdAt: Date;
  updatedAt: Date;
}

interface Permission {
  resource: ResourceType;
  actions: Action[];
  conditions?: Condition[];
}

type ResourceType = 
  | 'employee_data'
  | 'payroll_data'
  | 'expense_data'
  | 'compliance_reports'
  | 'ai_agent_config'
  | 'system_settings';

type Action = 'read' | 'write' | 'delete' | 'execute' | 'approve';

interface Condition {
  type: 'department' | 'location' | 'time_range' | 'data_classification';
  operator: 'equals' | 'contains' | 'in' | 'between';
  value: any;
}
```

**主要役割**:
- **従業員**: 自己データの閲覧、勤怠入力、経費申請
- **マネージャー**: 部下データの閲覧・承認、レポート閲覧
- **人事担当者**: 全従業員データ管理、人事プロセス実行
- **経理担当者**: 給与・経費データ管理、会計連携
- **経営層**: 全データ閲覧、戦略的レポート、AI設定承認
- **システム管理者**: 全機能アクセス、システム設定管理

#### 2.1.2 AIエージェント設定
```typescript
interface AgentConfiguration {
  agentId: string;
  agentType: AgentType;
  enabled: boolean;
  settings: {
    // 感度設定
    sensitivity: {
      alertThreshold: number; // 0-100
      anomalyDetection: 'low' | 'medium' | 'high';
      autoActionThreshold: number; // 自動実行の信頼度閾値
    };
    
    // 通知設定
    notifications: {
      channels: NotificationChannel[];
      recipients: NotificationRecipient[];
      frequency: 'realtime' | 'hourly' | 'daily' | 'weekly';
    };
    
    // 実行制限
    executionLimits: {
      maxActionsPerHour: number;
      requireApprovalFor: ActionType[];
      blackoutPeriods: TimeRange[];
    };
    
    // カスタムルール
    customRules: CustomRule[];
  };
}

interface NotificationChannel {
  type: 'email' | 'slack' | 'teams' | 'webhook';
  config: Record<string, any>;
}

interface CustomRule {
  id: string;
  name: string;
  condition: string; // JSONLogic形式
  action: string;
  priority: number;
}
```

### 3.2 データモデル
```sql
-- 役割と権限
CREATE TABLE roles (
  id UUID PRIMARY KEY,
  name VARCHAR(255) UNIQUE NOT NULL,
  description TEXT,
  priority INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE permissions (
  id UUID PRIMARY KEY,
  role_id UUID REFERENCES roles(id),
  resource VARCHAR(255) NOT NULL,
  actions JSONB NOT NULL,
  conditions JSONB,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- AIエージェント設定
CREATE TABLE agent_configurations (
  id UUID PRIMARY KEY,
  agent_id VARCHAR(255) UNIQUE NOT NULL,
  agent_type VARCHAR(100) NOT NULL,
  enabled BOOLEAN DEFAULT true,
  settings JSONB NOT NULL,
  created_by UUID REFERENCES users(id),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 監査ログ
CREATE TABLE audit_logs (
  id UUID PRIMARY KEY,
  timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  actor_id UUID REFERENCES users(id),
  actor_role VARCHAR(255),
  ip_address INET,
  user_agent TEXT,
  action_type VARCHAR(100),
  resource VARCHAR(255),
  changes JSONB,
  result VARCHAR(20),
  session_id UUID,
  correlation_id UUID,
  metadata JSONB
);

-- インテグレーション
CREATE TABLE integrations (
  id UUID PRIMARY KEY,
  service VARCHAR(100) NOT NULL,
  status VARCHAR(20) DEFAULT 'disconnected',
  authentication JSONB NOT NULL,
  sync_settings JSONB,
  health_check JSONB,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 4. UI/UXデザイン

### 4.1 ダッシュボード
- **概要ビュー**: システム全体の健全性、主要指標、アラート
- **エージェント状態**: 各AIエージェントの稼働状況、パフォーマンス
- **最近の活動**: 監査ログのサマリー、重要な変更履歴
- **クイックアクション**: よく使う設定へのショートカット

### 4.2 設定画面フロー
1. **カテゴリ選択**: 役割管理、エージェント設定、統合管理など
2. **詳細設定**: 各カテゴリ内の詳細パラメータ設定
3. **プレビュー**: 変更の影響をシミュレーション表示
4. **確認と適用**: 変更内容の最終確認と本番適用

### 4.3 会話型インターフェース
```
ユーザー: 「経理部門のAI承認感度を高めに設定して」
システム: 「経理部門の承認エージェントの異常検知感度を'high'に設定します。
          これにより、通常と異なるパターンの経費申請がより厳しくチェックされます。
          よろしいですか？」
ユーザー: 「はい」
システム: 「設定を変更しました。過去30日間の平均と比較して、
          約15%多くの申請が追加確認対象となる見込みです。」
```
