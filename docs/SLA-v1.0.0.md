# AI-OS サービスレベル契約書（SLA）
## Version 1.0.0

**発効日**: 2025年8月1日  
**最終更新日**: 2025年7月21日

## 1. 概要

本サービスレベル契約書（以下「本SLA」）は、AI-OS Corporation（以下「当社」）が提供するAI-Native Enterprise Operating System（以下「本サービス」）に関して、お客様に対して保証するサービスレベルを定義するものです。

## 2. サービス可用性

### 2.1 月間稼働率

当社は、本サービスの月間稼働率について以下を保証します：

| サービスプラン | 保証稼働率 | 計画メンテナンス時間（月間） |
|--------------|-----------|------------------------|
| スターター | 99.5% | 4時間 |
| プロフェッショナル | 99.9% | 2時間 |
| エンタープライズ | 99.95% | 1時間 |

### 2.2 稼働率の計算方法

```
月間稼働率 = (総時間 - ダウンタイム) / 総時間 × 100%
```

**除外事項**：
- 事前通知された計画メンテナンス
- お客様起因の問題
- 不可抗力（天災、戦争、テロ等）
- 外部サービスの障害

### 2.3 サービスクレジット

月間稼働率が保証値を下回った場合、以下のサービスクレジットを提供します：

| 実際の稼働率 | クレジット率 |
|------------|-----------|
| 99.0% - 99.5%未満 | 月額料金の10% |
| 95.0% - 99.0%未満 | 月額料金の25% |
| 95.0%未満 | 月額料金の50% |

## 4. データ保護とセキュリティ

### 4.1 データバックアップ

- **頻度**: 日次（差分）、週次（完全）
- **保持期間**: 30日間
- **復旧時点目標（RPO）**: 24時間
- **復旧時間目標（RTO）**: 4時間

### 4.2 セキュリティ保証

- **暗号化**: 保存時（AES-256）、通信時（TLS 1.3）
- **アクセス制御**: 多要素認証、RBAC
- **監査**: 全アクセスログの記録（7年間保存）
- **脆弱性対応**: 重大度に応じた対応時間
  - Critical: 24時間以内
  - High: 72時間以内
  - Medium: 7日以内
  - Low: 30日以内

## 5. サポートサービス

### 5.1 サポート時間

| プラン | サポート時間 | 対応言語 |
|--------|------------|---------|
| スターター | 平日 9:00-18:00 | 日本語 |
| プロフェッショナル | 平日 8:00-20:00 | 日本語、英語 |
| エンタープライズ | 24時間365日 | 日本語、英語、中国語 |

### 5.2 応答時間目標

| 優先度 | 定義 | 初回応答 | 解決目標 |
|--------|------|---------|---------|
| P1 - 緊急 | サービス停止、重大なデータ損失リスク | 30分 | 4時間 |
| P2 - 高 | 主要機能の障害、パフォーマンス重大劣化 | 2時間 | 24時間 |
| P3 - 中 | 一部機能の障害、回避策あり | 8時間 | 72時間 |
| P4 - 低 | 軽微な問題、機能改善要望 | 24時間 | ベストエフォート |

## 6. メンテナンス

### 6.1 計画メンテナンス

- **通知期間**: 7日前までにメールおよびシステム内通知
- **実施時間**: 
  - 日本時間 深夜2:00-6:00を基本とする
  - エンタープライズプランは個別調整可能

### 6.2 緊急メンテナンス

- **実施条件**: セキュリティ脅威、データ損失リスクがある場合
- **通知**: 可能な限り事前通知（最短30分前）

## 8. データ所有権と移行

### 8.1 データ所有権

- お客様のデータは100%お客様に帰属
- 当社はサービス提供に必要な範囲でのみ使用

### 8.2 データエクスポート

- いつでもデータエクスポート可能
- 標準フォーマット（CSV、JSON、XML）対応
- 契約終了後30日間はデータアクセス可能

## 9. 責任制限

### 9.1 補償上限

- サービスクレジットの総額は、影響を受けた月の月額料金を上限とする
- 間接的損害、逸失利益については責任を負わない

### 9.2 免責事項

以下の場合、当社は本SLAの義務を免除される：
- お客様の作為・不作為に起因する問題
- 当社の合理的な管理を超えた事象
- お客様による利用規約違反

## 10. SLAの変更

### 10.1 変更通知

- 重要な変更は90日前までに通知
- 軽微な変更は30日前までに通知

### 10.2 変更への同意

- 変更に同意できない場合、通知から30日以内に契約解除可能
- 解除の場合、前払い料金は日割りで返金

## 11. 報告とレビュー

### 11.1 月次レポート

以下を含む月次サービスレポートを提供：
- 稼働率実績
- パフォーマンス指標

### 11.2 四半期レビュー
