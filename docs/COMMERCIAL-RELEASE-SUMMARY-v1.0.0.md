## 🚀 デプロイメント手順

### 1. 環境準備
```bash
# 本番環境の環境変数設定
export DB_PASSWORD="your-secure-password"
export JWT_SECRET="your-jwt-secret"
export REDIS_PASSWORD="your-redis-password"
# ... その他の環境変数
```

### 2. デプロイ実行
```bash
# デプロイスクリプトの実行
./scripts/deploy.sh deploy

# ヘルスチェック
./scripts/deploy.sh health
```

### 3. 初期データ投入
```bash
# 本番データベースに初期データを投入
psql -h prod-db.ai-os.com -U aios_app -d aios_production < scripts/seed-data.sql
```
