# v3.2.0 エンタープライズ設定管理コンソール 統合ガイド

## 概要
AI-OS v3.2.0 エンタープライズ設定管理コンソールは、AIエージェントの強力な自律性をエンタープライズ環境で安全かつ効果的に運用するための統合管理ダッシュボードです。

## アーキテクチャ

### バックエンド
- **APIサーバー**: `src/api-server.ts`
- **エンドポイント**: `/api/v3.2.0/*`
- **ポート**: 3001（デフォルト）
- **データベース**: PostgreSQL

### フロントエンド
- **場所**: `src/v3.2.0/enterprise-console/`
- **フレームワーク**: React + Material-UI
- **ビルドツール**: Vite
- **ポート**: 5173（デフォルト）

## セットアップ手順

### 1. 依存関係のインストール

```bash
# ルートディレクトリで
npm install

# エンタープライズコンソールディレクトリで
cd src/v3.2.0/enterprise-console
npm install
cd ../../..
```

### 2. データベースの準備

```bash
# PostgreSQLコンテナの起動
npm run postgres:start

# データベースの初期化
npm run db:init

# v3.2.0用のテーブル作成
psql -U aiuser -d ai_native_hr_platform -f src/v3.2.0/enterprise-console/database-schema.sql
```

### 3. 環境変数の設定

`.env`ファイルを作成：
```env
# データベース設定
DATABASE_URL=postgresql://aiuser:aipass123@localhost:5432/ai_native_hr_platform

# APIサーバー設定
API_PORT=3001

# フロントエンドURL
FRONTEND_URL=http://localhost:5173

# JWT設定（本番環境では必ず変更してください）
JWT_SECRET=your-secret-key-here
```

## 起動方法

### 開発環境

1. **APIサーバーの起動**:
```bash
npm run api:dev
```

2. **エンタープライズコンソールの起動**:
```bash
npm run console
```

3. **アクセス**:
- API: http://localhost:3001/api/v3.2.0
- コンソール: http://localhost:5173/enterprise-console/
- ヘルスチェック: http://localhost:3001/health

### 本番環境

1. **ビルド**:
```bash
# TypeScriptのビルド
npm run build

# エンタープライズコンソールのビルド
npm run console:build
```

2. **起動**:
```bash
# APIサーバー
NODE_ENV=production node dist/api-server.js

# 静的ファイルの配信（Nginxなどを使用）
```

### 1. 役割ベースアクセス制御（RBAC）
- 詳細な権限設定
- 階層的な権限管理
- 条件付き権限（金額上限、時間制限など）

### 2. AIエージェント管理
- エージェントの有効/無効切り替え
- 感度（アラート閾値）の調整
- 通知先の設定
- パフォーマンス監視

### 3. 統合管理ハブ
- 外部サービス連携状況の一覧
- OAuth 2.0認証管理
- WebhookとAPI設定
- エラーログとリトライ管理

### 4. ハイブリッド設定インターフェース
- GUIによる直感的な操作
- AI会話型設定（自然言語での設定変更）
- 設定の一括エクスポート/インポート

### 5. 監査とコンプライアンス
- 全設定変更の完全追跡
- 監査ログの検索とフィルタリング
- コンプライアンスレポート生成
- データガバナンス設定

## トラブルシューティング

### APIサーバーが起動しない
1. PostgreSQLが起動しているか確認
2. ポート3001が使用されていないか確認
3. 環境変数DATABASE_URLが正しいか確認

### フロントエンドからAPIに接続できない
1. CORSの設定を確認
2. プロキシ設定（vite.config.ts）を確認
3. APIサーバーが起動しているか確認

### 権限エラーが発生する
1. JWTトークンが有効か確認
2. ユーザーの役割が正しく設定されているか確認
3. 権限の階層構造を確認

## セキュリティ考慮事項

1. **本番環境では必ずHTTPSを使用**
2. **JWT_SECRETは強固なランダム文字列に変更**
3. **データベースの認証情報は環境変数で管理**
4. **定期的な監査ログのレビュー**
5. **最小権限の原則に従った権限設定**
